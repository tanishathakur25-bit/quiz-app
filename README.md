🤖 AI Quiz Generator

An interactive web application that generates quiz questions using AI.
Users can enter a topic, and the application will generate a simple quiz question and answer related to that topic.

This project uses HTML, CSS, JavaScript, and the Gemini API to generate quiz questions dynamically.

🚀 Features

Generate quiz questions on any topic

AI-powered question generation

Simple and clean user interface

Instant results

Beginner-friendly project

🛠️ Technologies Used

HTML

CSS

JavaScript

Google Gemini AI API
📸 How It Works

Enter a topic (for example: Photosynthesis).

Click the Generate Question button.

The AI generates:

A quiz question

Its answer
